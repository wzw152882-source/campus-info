## 它做什么

- **三通道巡检**：学校官网 8 个栏目 + 学院公众号 + 年级群，每天自动抓
- **日期归一**：「本周五」「三天内」「9 月 30 日前」统一折算成绝对日期，不猜、不编
- **跨源判重**：同一份附件在微信和官网都出现时，标「官网已有」
- **价值排序**：按本校官方推免文件（成绩×85% + 思想素养×5% + 综合素质×10%，附竞赛清单）给每条通知定级，再叠加截止时间
- **抢名额雷达**：命中「限 N 人、先到先得」的通知 30 分钟内推送到手机

## 这个仓库是什么

- 默认分支 `gh-pages` 里放的是**构建产物**（HTML / JSON），源码在工作机上，不在这个仓库
- 页面**已脱敏**：剔除了含成绩排名、转专业公示的条目，无学号、无手机号
- 数据每天更新
